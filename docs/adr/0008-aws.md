# ADR-0008: Target Cloud Infrastructure (AWS)

## Status
ACCEPTED

## Date
2026-09-16

## Context
We need a robust, scalable cloud platform providing managed PostgreSQL, Redis, container runtime, KMS encryption, and object storage with global compliance certifications.

## Decision
Design primary infrastructure targeting AWS (Aurora Serverless, ECS Fargate, S3, ElastiCache, KMS) managed with Terraform, while maintaining container-level cloud portability.

## Alternatives Evaluated
* **GCP / Azure**: Strong alternatives, but team familiarity and AWS enterprise compliance ecosystem favor AWS.
* **Bare Metal**: Unnecessary operational overhead for early stage.

## Consequences
* **Positive**: Mature managed primitives, high availability, comprehensive security controls.
* **Negative**: Cloud costs require active monitoring and budget alarms.
