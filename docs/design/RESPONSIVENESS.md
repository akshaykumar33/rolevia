# Responsive Design Guidelines

Rolevia layouts adapt across desktop, tablet, and mobile displays without losing functional capability.

---

## Breakpoints & Adaptations
* **Desktop (`>= 1024px`)**: Persistent left sidebar, multi-pane split editors for resume tailoring.
* **Tablet (`768px - 1023px`)**: Collapsible compact icon sidebar, stacked tailoring panels with tabs.
* **Mobile (`< 768px`)**: Bottom sheet navigation, simplified cards replacing complex data tables, swipe gestures for quick review.
