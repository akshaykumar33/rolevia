# Page Patterns & Layout Archetypes

Standardized structural patterns for Rolevia application views.

---

## Standard Layout Patterns
1. **Workbench View**: Split-pane layout (e.g. Application Studio with target JD on the left and tailored materials on the right).
2. **Catalog / List View**: Search bar and multi-select filter ribbon at the top, scrollable virtualized item cards below.
3. **Detail Drawer**: Sliding right-hand drawer for inspecting granular provenance and audit logs without navigating away from the current context.
4. **Modal Dialog**: Centered overlay for critical confirmations (destructive actions, human approval of external submission).
