# Typography System

Rolevia uses a clean, highly legible variable font stack optimized for high-density SaaS interfaces.

---

## Font Family Stack
* **Primary / Sans**: `Inter, -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`
* **Mono / Technical**: `JetBrains Mono, "Fira Code", monospace`

---

## Scale Hierarchy
* `display`: 32px / 1.2 / 700 (Dashboard hero stats)
* `heading`: 20px / 1.3 / 600 (Section headings)
* `subheading`: 16px / 1.4 / 600 (Card titles)
* `body`: 14px / 1.5 / 400 (General interface text)
* `caption`: 12px / 1.4 / 500 (Badges, metadata, timestamps)
* `code`: 13px / 1.4 / 400 (Tokens, skill keywords)
