# Design Tokens

Semantic tokens isolate styling intent from raw values, powering full dark and light mode adaptation.

---

## Semantic Tokens Directory

| Token | Dark Default | Light Default | Purpose |
| ----- | ------------ | ------------- | ------- |
| `--bg-base` | `#0b0f17` | `#ffffff` | Primary background canvas |
| `--bg-surface` | `#111827` | `#f8fafc` | Card and component surface |
| `--bg-surface-raised` | `#1f2937` | `#f1f5f9` | Modal, popover, raised element |
| `--text-primary` | `#f9fafb` | `#0f172a` | High-contrast body & headings |
| `--text-muted` | `#9ca3af` | `#64748b` | Secondary labels & metadata |
| `--border-subtle` | `#1f2937` | `#e2e8f0` | Subtle boundaries & dividers |
| `--border-strong` | `#374151` | `#cbd5e1` | Form inputs & active borders |
| `--accent-primary` | `#38bdf8` | `#0284c7` | Brand focal points & primary CTAs |
| `--status-success` | `#10b981` | `#059669` | Verified claims, successful sync |
| `--status-warning` | `#f59e0b` | `#d97706` | Inferred claims, missing evidence |
| `--status-danger` | `#ef4444` | `#dc2626` | Gaps, errors, emergency stop |
