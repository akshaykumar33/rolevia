# Spacing & Layout System

Rolevia adheres to a strict 4px/8px incremental spacing scale.

---

## Scale Values

- `space-1`: 4px (tight badge padding)
- `space-2`: 8px (icon gaps, button horizontal pad)
- `space-3`: 12px (form input padding)
- `space-4`: 16px (card padding)
- `space-6`: 24px (section margins)
- `space-8`: 32px (page layout gutters)
