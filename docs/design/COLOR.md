# Color Palette System

Rolevia's palette uses tailored HSL values emphasizing clarity, contrast, and calm professionalism.

---

## Palette Values

- **Slate/Neutral**: `slate-950` (#0b0f17) to `slate-50` (#f8fafc)
- **Cyan/Sky Accent**: Primary brand highlight with high legibility across dark and light modes.
- **Emerald**: Positive verification, matches > 80%.
- **Amber**: Warnings, unconfirmed facts.
- **Rose/Red**: Gaps, errors, critical actions.
