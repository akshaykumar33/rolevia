# Accessibility Standards (WCAG 2.1 AA)

Accessibility is non-negotiable and part of the Definition of Done.

---

## Invariants
1. **Keyboard Navigability**: Every interactive element (button, tab, modal, dropdown) must be fully operable using keyboard only (`Tab`, `Shift+Tab`, `Enter`, `Escape`).
2. **Focus Indicators**: High-contrast, visible focus rings on all focused inputs and buttons.
3. **Contrast Ratios**: Minimum 4.5:1 for normal text, 3:1 for large headings and icons against their background surfaces.
4. **ARIA Roles**: Explicit `role`, `aria-expanded`, and `aria-label` where semantic HTML is insufficient.
